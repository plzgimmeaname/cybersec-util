      Version – · checks follow CIS Controls v8 and NIST SP 800-53

      What it reads

      Settings and lists on this computer: security settings, app names and versions, startup items, accounts, browser add-on names, and network settings. It never reads your documents, passwords or browsing history, and it never changes anything.

      What goes online

      Only two things. The update check asks Apple, Microsoft or your Linux system if updates are waiting. The unsafe-versions check sends app names and version numbers (like "chrome 141") to nvd.nist.gov, the U.S. government's vulnerability list.
