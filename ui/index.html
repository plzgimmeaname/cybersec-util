          Privacy

          What it reads

          Settings and lists on this computer: security settings, app names and versions, startup items, accounts, browser add-on names, and network settings. It never reads your documents, passwords or browsing history. It only changes something when you press a fix button and approve it.

          What goes online

          Update checks ask Apple, Microsoft or your Linux system what is waiting. The unsafe-versions check sends app names and versions (like "chrome 141") to nvd.nist.gov. The network tests open secure connections to google.com, github.com, cloudflare.com and microsoft.com to read their certificates, fetch tiny test pages from detectportal.firefox.com and captive.apple.com, look up a few made-up names, ask Cloudflare for the time, and probe this computer's own address and your local network for routers. No personal data is sent.
